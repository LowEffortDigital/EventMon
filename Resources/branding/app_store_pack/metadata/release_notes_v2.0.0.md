# EventMon v2.0.0 for macOS

## What's New in v2.0.0

### 🚀 Low Effort Suite v2.0 Standardization (`PerfMon`, `EventMon`, `VolMon`, `WebMon`)
- **Renamed to EventMon v2.0.0 (`com.loweffort.eventmon`)**: Unified product naming, `EM` / `EE` / `LE` monograms, and cross-suite discovery across all four Low Effort Suite v2.0 macOS utilities (`PerfMon`, `EventMon`, `VolMon`, and `WebMon`).
- **Seamless Preference Migration**: Automatically migrates existing `EventViewer` v1 preferences (`com.loweffort.eventviewer`) and legacy `EV` monograms to `EventMon` v2.0 (`EM`) on first launch.
- **4-App Theme, Accent & Persistent Dock Icon Sync**: Detect and synchronize themes, custom accent hex colors, monogram roles, and HUD opacity across `PerfMon`, `EventMon`, `VolMon`, and `WebMon` in one click.
- **Native Desktop Widget Layer & Magnetic 16pt Grid Snapping**: Desktop widgets sit at `kCGDesktopIconWindowLevel + 2` with magnetic 16pt grid snapping across Notification Center and all Low Effort Suite sibling widgets, plus complete Dock-free accessory mode.

### 📊 Visual Widget Gallery & Eight Event Graph Styles
- Includes the 6-preview widget gallery, optional rounded **Cards** presentation, and 8 graph styles (`Win11 Grid`, `Sparkline`, `Gauges`, `Large Readout`, `History Bars`, `Stacked Severity`, `Severity Ring`, and `Error / Warning Area`).
