# EventMon v2.0.1 for macOS (Build 22)

## What's New in v2.0.1
- **Homogenized Tactile `LowEffortButtonStyle`**: Upgraded all interactive action buttons across the suite with elevated gradient surfaces, top specular highlights, crisp borders, and press-scale feedback so interactive controls are immediately distinguishable from status pills.
- **Active-Display Multi-Monitor Widget Placement & Always-on-Top Migration**: Desktop HUDs and Card widgets automatically spawn and restore on your active display (`preferredActiveScreen()`), persist `displayID` and `screenLocalizedName` across multi-monitor setups, and migrate smoothly to default floating window levels.
- **Low Effort Suite v2.0 Sync**: Full cross-app theme, custom hex accent, monogram (`EM`/`EE`/`LE`), and persistent `.app` Dock icon synchronization across **EventMon**, **PerfMon**, **VolMon**, and **WebMon**.
- **5-Channel Unified Log Explorer & 3-Column Correlation Flow Map**: Structured Windows 11 Event Viewer channels (`System`, `Security`, `Application`, `Kernel`, `Network`), Windows `<Event>` XML + JSON split inspector, `.ips`/`.crash` forensics, and 8 buffered event graph styles.
